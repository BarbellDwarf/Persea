# Security Audit: Injection, Auth, and Crypto Review

## Question

What injection vectors, auth weaknesses, and crypto weaknesses exist in persea's current codebase? Map every SQL query, every user-input handling path, every crypto operation, every auth flow, and flag anything that could be exploited. Include CSRF, XSS, SSRF, session fixation, timing attacks, and information disclosure.

## Deliverable

A structured report: file:line for each finding, severity (Critical/High/Medium/Low), exploitation path, and recommended fix. Group by category.
