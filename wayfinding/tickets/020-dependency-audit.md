# Dependency Audit: Current Versions and Known CVEs

## Question

Which Cargo.toml dependencies are outdated, and do any have known CVEs? Check every crate against crates.io for the latest version, and check RustSec/RUSTSEC advisories for known vulnerabilities.

## Deliverable

A table: crate | current version | latest version | update priority (Critical/High/Medium/Low) | CVE reference if any.
