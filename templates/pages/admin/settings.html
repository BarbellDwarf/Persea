Storage Backends

Connection credentials are read server-side when a session starts and never reach the browser. Where they are kept is a deployment decision between two backends.

Pros and cons of each backend, plus setup steps, are in the deployment guide's storage section.

Customization

Connection custom fields add optional extra inputs (e.g. Environment, Owner, Cost Center) to connection entry forms and to the filter bar on the Connections page. Off by default; add a field below to enable them.

Software Updates

Update checks run on the server and are configured in the persea config file under the [updates] section: enabled, check_url and check_interval_hours. When a newer stable release exists, an admin banner links to it.

Air-gapped deployments disable the check with enabled = false, or point check_url at an internal mirror. See the deployment guide for details.
